---
title: "Glossary"
description: 'The words used in the app and these guides.'
---

| Word | Meaning |
| --- | --- |
| **Agent / Admin** | The two roles. Admins can do everything; agents work in the inbox and campaigns. |
| **Assignee** | The person (or the AI assistant) who owns a conversation. |
| **Participant** | An extra person added to a chat who may reply but does not own it. |
| **Audience** | The group of people a campaign goes to: a tag, an import, a saved audience or a filter. |
| **Audit log** | A permanent record of who did what and when. |
| **Campaign** | One message sent to many people, paced for safety. |
| **Cooldown** | People messaged by a campaign in the last 14 days are skipped by a new one. |
| **Custom field** | An extra column of your own on each contact, usable in messages as `{{field}}`. |
| **Do not contact** | A flag meaning never message this person. |
| **Draft** | A campaign that has been created but not started. Nothing is sent. |
| **Gate** | A safety check a message must pass before it is sent. |
| **Linked number** | A WhatsApp number connected to the CRM so it can send and receive. |
| **Pacing** | Spacing messages out over time like a person would. |
| **Queue (AI)** | The waiting list of requests to the AI assistant, run one at a time. |
| **Quarantined** | A number the CRM has paused because it looks risky. |
| **Saved audience (segment)** | A filter you name and reuse. |
| **Spintax** | The `{Hi|Hey|Hello}` notation that makes each person get slightly different wording. |
| **Tag** | A label on a contact such as "pune". |
| **Warm-up** | The slow start of a new number: a low daily allowance that grows with time. |
